# 🎓 КГУ Студент — Расписание & Менеджер домашних заданий

Полноценное веб-приложение для студента **Костромского государственного университета (КГУ)**, объединяющее актуальное расписание занятий группы **26-ИСбо-4 (ID: 8953)** и премиальный менеджер домашних заданий в минималистичном дизайне **Apple (macOS / iOS)**.

---

## ✨ Ключевые возможности

### 1. Дизайн в стиле Apple
- Эстетика **macOS Sonoma** и **iOS 18**: скруглённые карточки (`rounded-3xl`), деликатные тени, полупрозрачные стеклянные панели (`backdrop-blur-xl`), типографика в духе **SF Pro Display / Text**.
- **Светлая и тёмная темы** с поддержкой системных настроек и плавным переключением.
- Единый стиль иконок **Lucide React**.
- Адаптивный интерфейс: боковая панель (Sidebar) для компьютеров и нижняя плавающая панель навигации (Dock) для смартфонов и планшетов.
- **100% русский язык** интерфейса, дат и уведомлений.

### 2. Главный экран «Сегодня»
- Текущая дата, день недели на русском языке и динамическое приветствие («Доброе утро / день / вечер»).
- Сводка учебной нагрузки: количество пар сегодня, активных ДЗ, долгов.
- **Интерактивный баннер ближайшей пары**:
  - Отображает номер пары, время начала и окончания.
  - Живой статус: «Идёт сейчас (осталось 25 мин)» или «Следующая пара через 40 мин».
  - Преподаватель, расшифрованное здание и аудитория (например, «Корпус «Б», ауд. 407»).
- Полный хронологический список занятий на сегодня с визуальным выделением активной пары.
- Виджет дедлайнов на сегодня и блок просроченных заданий.
- Информативное сообщение для выходных дней без пар.

### 3. Расписание занятий с сайта КГУ
- Интеграция с официальной системой: `https://eios.kosgos.ru/WebApp/#/Rasp/Group/8953`.
- Просмотр недели с переключением между днями (Пн–Сб).
- Навигация по неделям (Предыдущая / Текущая / Следующая).
- Отображение типа недели: **Числитель (над чертой)** или **Знаменатель (под чертой)**.
- Цветные бейджи типов занятий:
  - 🔵 **Лекция** (синий бейдж)
  - 🟢 **Практика** (изумрудный бейдж)
  - 🟠 **Лабораторная работа** (янтарный бейдж)
  - 🔴 **Экзамен / Зачёт / Замена**
- Фильтрация по подгруппам: **Вся группа**, **1-я подгруппа**, **2-я подгруппа**.
- Поиск по названию дисциплины, преподавателю или аудитории.
- Переключение между сеточным видом недели и детальным просмотром одного дня.
- Карточка пары с возможностью в один клик создать домашнее задание по выбранному предмету.
- Информация о дате и времени последней синхронизации расписания сервером КГУ.

### 4. Менеджер домашних заданий
- Полноценный учёт студенческих задач:
  - Название, предмет (автоматический список дисциплин из расписания + ручной ввод).
  - Подробное описание и требования преподавателя.
  - Дата выдачи, дата и время сдачи (дедлайн).
  - Приоритет: **Низкий**, **Обычный**, **Высокий**.
  - Статус: **Не начато**, **В работе**, **Выполнено**.
  - Интерактивный **чек-лист подзадач** с прогресс-баром.
  - Ссылки на материалы (СДО КГУ, облачные диски, GitHub).
  - Личные заметки.
- Тактильные круглые чекбоксы в стиле **Apple Reminders** со звуковым откликом при выполнении.
- Сегментированные вкладки: «Все», «Сегодня», «На этой неделе», «Просроченные», «Выполненные».
- Сортировка по дедлайну, приоритету и дате добавления.
- Модальное окно подтверждения перед удалением для защиты от случайной потери данных.

### 5. Календарь
- Интерактивная сетка месяца с цветными точками-индикаторами:
  - Синяя точка — пары в расписании.
  - Оранжевая точка — дедлайн домашнего задания.
  - Красная точка — контрольная работа или экзамен.
- Панель дня: при клике на дату открывается объединённая хронология всех событий, пар и заданий за этот день.
- Возможность добавлять собственные события: **Контрольная работа**, **Экзамен**, **Коллоквиум**, **Сдача проекта**.
- Режим отображения «События и дедлайны» (Agenda).

### 6. Уведомления и сохранение данных
- Поддержка системного **Web Notifications API** браузера.
- Воспроизведение чистого звукового сигнала (колокольчика) через синтезатор **Web Audio API** без внешних аудиофайлов.
- Проверка тестового уведомления в настройках.
- Экспорт всей базы заданий и событий в человекочитаемый файл `JSON`.
- Импорт и восстановление данных из резервной копии.
- Автоматическое кэширование расписания в `localStorage` (приложение мгновенно открывается даже без доступа к интернету).

## 📡 Как работает получение расписания с сайта КГУ

При исследовании веб-приложения ЭИОС КГУ (`https://eios.kosgos.ru/WebApp/#/Rasp/Group/8953`) было установлено:

1. **SPA-клиент**: Портал построен на Vue.js и загружает чанки скриптов (в частности, `js/rasp.93f8fbe0.js`).
2. **Публичный REST API**:
   - `GET https://eios.kosgos.ru/api/Rasp?idGroup=8953` возвращает полное расписание группы на семестр (349 занятий в формате JSON).
   - `GET https://eios.kosgos.ru/api/Rasp?idGroup=8953&sdate=YYYY-MM-DD` возвращает расписание на конкретную неделю.
   - `GET https://eios.kosgos.ru/api/GetRaspDates?idGroup=8953` возвращает диапазон дат семестра (`minDate`, `maxDate`).
3. **Ограничение CORS**:
   - Сервер `eios.kosgos.ru` (nginx/1.26 + ASP.NET) не передаёт HTTP-заголовок `Access-Control-Allow-Origin: *`.
   - Из-за этого прямой запрос через `fetch` из браузера блокируется политикой безопасности браузера.
4. **Решение проблемы**:
   - Разработан серверный модуль `server/server.js` на Node.js / Express, который выполняет серверный запрос к `https://eios.kosgos.ru/api/Rasp` без ограничений браузера и отдаёт данные клиенту.
   - В режиме разработки Vite дополнительно настроен dev-прокси (`/api-eios` и `/api`).
5. **Офлайн-надежность**:
   - При успешном запросе данные сохраняются в `localStorage`.
   - При отсутствии сети или сбоях сервера КГУ приложение автоматически переключается на кэш или встроенный снимок расписания группы 8953 (349 занятий).

## 🚀 Инструкция по запуску на Windows

### Способ 1: Запуск в один клик (Рекомендуется)

Просто дважды кликните по файлу **`start.bat`** в папке проекта `c:\Projects\Rasp\start.bat`.

Скрипт автоматически:
1. Проверит наличие Node.js.
2. Установит зависимости (если не были установлены).
3. Соберёт проект.
4. Запустит сервер и откроет приложение в вашем браузере по адресу:
   **`http://localhost:3000`**

---

### Способ 2: Запуск через терминал (PowerShell / Командная строка)

1. Откройте PowerShell в папке проекта:
   ```powershell
   cd c:\Projects\Rasp
   ```

2. Убедитесь, что Node.js доступен в PATH, и запустите сервер:
   ```powershell
   npm start
   ```

3. Откройте в браузере:
   ```
   http://localhost:3000
   ```

---

### Способ 3: Запуск в режиме разработки с Hot Module Replacement (HMR)

Если вы хотите вносить изменения в исходный код и видеть обновления на лету:

```powershell
npm run dev
```

Vite запустит dev-сервер по адресу `http://localhost:5173`.

## 💾 Резервное копирование и сохранность данных

Все ваши домашние задания, чек-листы и созданные контрольные точки сохраняются локально на вашем компьютере.

Чтобы сделать резервную копию:
1. Перейдите в раздел **Настройки**.
2. Нажмите кнопку **«Экспорт в JSON»**.
3. Файл `ksu_planner_backup_YYYY-MM-DD.json` сохранится в папку «Загрузки».
4. Вы можете восстановить его в любой момент на любом устройстве через кнопку **«Импорт из JSON»**.
